# Customer Behaviour Analysis PowerBI
## Overview
This project focus on generating insights on Behaviour patern of customer and visualization of the insights in a interactive dashboard that can be understood by both technical and non technical stake holders.
We have used the CSV files, used pandas for generating and exploring data within Jupyter Notebook, and finally loading data into the SQL DB for Business Analysis and Dashboard is created in Power BI.

---

## Tech Stack
- **Database**: PostgreSQL
- **Data Sources**: CSV File 
- **Language**: Python
